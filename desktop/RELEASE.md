# 静观 TV Windows 免安装版 v2.19.2-desktop.8

Windows 免安装版更名为 **静观 TV**，与 Android 手机 / TV 通用版同名。2026-10-25 更新下载包中的源配置：现含 **9 个点播源、9 个直播源**（新增「魔都动漫」「樱花资源」）。本版提供 **7z 下载包**，并优化了搜索与封面加载的等待体验。Android 手机 / TV 通用版当前为 2.0.14。

## 使用

完整解压所选压缩包后，打开解压出来的 `LibreTV-App` 文件夹，双击 `静观TV.exe`。无需安装 Node.js、Docker 或其他运行环境。

升级用户请先关闭旧版，用新版文件夹里的程序文件覆盖旧文件夹中除 `LibreTV-Data` 以外的全部内容，保留自己的 `LibreTV-Data`，不要用随包数据覆盖已有记录。希望从空白配置开始的用户，可在首次运行前将随包数据目录移走备份。

已有 Windows 用户若只想补充最新源，请在源管理的订阅入口添加：
https://raw.githubusercontent.com/wangshaojie/LibreTV-App/main/sources/latest.json

包内另附 `LibreTV-Sources.json`，供迁移、托管订阅或导入 Android 使用。

## 本版本

- **搜索更利落**：单个点播源的超时上限从 10 秒收紧到 6 秒——实测多数源站 0.6~1.5 秒就有响应，坏源不再拖住整轮搜索。结果区新增「重试 N 个失败源」按钮，只补跑失败的源，已经出来的结果不会消失重来。
- **图片代理加并发闸门与内存缓存**：首页一次要拉几十张封面，此前无节制并发转发容易把连接池打满，表现为滚动时掉帧；现在同一时刻在途的图片请求有上限，同一张图也不再重复出网。
- **首页推荐区改为滚近视口才挂载**：首屏先把搜索框交到手上，推荐网格的 DOM 与首屏请求都更轻。
- **新增 7z 格式下载包（约 109 MB）**，比 ZIP（约 158 MB）小约三分之一。Windows 11 22H2 及以后的文件资源管理器原生支持解压 7z；Windows 10 用户或习惯 ZIP 的用户仍可下载 ZIP 包，两者内容完全一致。
- **改为目录分发，启动从约 28 秒降到约 1 秒**（2.19.2-desktop.6 起）。上一版是单个 EXE，每次启动都要把约 460 MB 的运行时重新解压到系统临时目录，并被杀毒软件逐个实时扫描，窗口要等近 30 秒才出现；现在解压后直接运行 `静观TV.exe`，不再重复解压，也不再每次产生一批新文件。功能完全一致，只是程序文件不再压缩进单个 EXE。
- 精简 Electron 的多语言界面包：只保留简体中文、繁体中文和英文，其余 52 个语言包不再随包分发，节省约 45 MB。
- **自动清理浏览器缓存**：Chromium 的图片缓存一度把数据目录撑到 370 MB 以上，现在启动后会检查并清理超量的可再生缓存目录，不再无限膨胀；源配置、收藏和观看记录不受影响。
- 新增启动阶段打点日志：`LibreTV-Data/desktop.log` 中 `[boot]` 开头的行记录了各阶段耗时，便于定位启动问题。
- **随包源配置更新为 9 个点播源、9 个直播源**（新增「魔都动漫」「樱花资源」两个动漫向点播源）。包内附官方清单副本 `LibreTV-Sources.json`，可在「设置 → 源管理 → 数据源订阅」手动导入；启动时也会自动合并官方清单。
- **新增：启动时自动获取项目维护的官方片源清单**。清单地址由维护者控制，用户只能读取、无法改写。合并规则：新增的源自动补入并默认启用，你手动停用的源保持停用，你自己添加的源不受影响，你删除过的官方源不会被自动加回。清单拉取失败时静默降级，本地配置保持原样，不影响使用。
- 应用更名为 **静观 TV**：窗口标题、任务栏与开始菜单名称、程序菜单、网页界面和安装包内的 EXE 全部同步更新。
- **数据目录名保持 `LibreTV-Data` 不变**：覆盖升级后原有源配置、设置和观看记录继续可用，不需要迁移，也不会丢数据。
- 下载包文件名保持 ASCII，不引入中文 URL 编码问题；包内可直接双击的 EXE 为 `静观TV.exe`。
- 保留逐跳目标校验，兼容重定向、Range、流式传输和超时中断。
- 本地数据随 EXE 保存，便于备份和迁移。
- 上一版 2.19.2-desktop.2 修复了内置服务没有跟随 Windows 系统代理/PAC、导致部分 M3U 订阅下载失败的问题，本次改动不涉及该逻辑。
- Android 通用版当前为 2.0.14（静观 TV），兼容手机及 Android TV：https://github.com/wangshaojie/LibreTV-App/releases/tag/android-v2.0.14

在线内容需要联网，线路是否可播取决于网络、地区、源站和编码。本构建未做数字签名。
