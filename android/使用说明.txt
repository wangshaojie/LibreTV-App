LibreTV-App Android 1.0.2 · 手机 / Android TV 通用版

修复 Android 5–7 旧证书库导致的 HTTPS 订阅读取失败，证书校验仍然开启。

源配置更新于 2026-10-23：7 个点播源、9 个直播源。
1.0.0 用户直接覆盖安装，自动补入新增 6 个源，保留自定义配置、收藏和记录。不要先卸载。

安装 universal.apk 即可，最低 Android 5.0，无需连接 Windows 或部署服务器。
同一安装包支持触屏手机、平板及 Android TV。电视端可以从电视桌面启动。

直播：选择直播源，按分组浏览或搜索节目。M3U 列表请添加到「直播」类型。
点播：填写片名搜索已添加的 Apple CMS JSON 源，选择影片、线路和剧集。
源管理：支持新增、编辑、删除、测试及 JSON 导入导出。
收藏：长按节目，或在播放器中点击「收藏」。电视上也可用菜单键。
续播：点播退出时保存进度，在「记录」打开可继续播放。
遥控器：方向键移动焦点，确定键操作，返回键退回，媒体播放/暂停键控制播放。

已带入此前 Windows 公开包的源配置，没有带入 Windows 的观看记录或 Cookies。
网络请求由 Android 设备直接发起，依赖代理的地址需要在设备上自行配置网络。
第三方源可能失效，也可能受运营商、地区、编码限制。列表能导入不代表每个节目都能播放。
不支持需要专用引擎的 Spider 源或网页解析线路；EPG、离线下载等功能尚未移植。

源码与更新：https://github.com/wangshaojie/LibreTV-App
