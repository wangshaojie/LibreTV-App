# 静观 TV Android 2.0.13 · 网络层统一 + 官方清单新增两个动漫源

上一版把两个安装包合并成了一个，本版处理的是老电视上的网络细节：让「源管理」里看到的连接状态，和应用里实际能不能搜到片，真正对得上。

## 改动

- **官方片源清单新增两个点播源**：「魔都动漫」（国产 / 日韩 / 欧美 / 港台动漫、动漫电影）与「樱花资源」（动漫、动画电影）。点播源共 9 个、直播源 9 个。新增源会在客户端自动补入并默认启用，手动停用过的源保持停用，自己添加的源不受影响。
- **IPv4 回退改为自建连接**：老电视所在路由器常返回 IPv6 地址，但电视没有 IPv6 路由，Android 5.0 底层又不会自动回退，第一个连接直接 `ENETUNREACH`。此前的做法是改成 IP 直连，虽然能连上，却丢掉了 SNI——Cloudflare 这类站点会拿默认证书回应，证书对不上域名。现在改为自建连接：直连该主机的 IPv4 地址，同时按原主机名发送 SNI、按原主机名校验证书，安全检查一步都不少。
- **老系统补上 TLS 1.1 / 1.2**：部分 Android 5 的电视默认只协商 TLS 1.0，而大量现代站点已经关掉 TLS 1.0/1.1，握手会直接收到 `unsupported protocol`。本版在保留 TLS 1.0 的前提下把更高版本补进协商列表：服务器支持就用高版本，不支持仍旧回落 TLS 1.0，原先能连的站点不受影响。
- **测活与海报走同一条通道**：「源管理 → 全部测活」和首页海报此前各自建连，没有继承上面两条改进，于是会出现「源显示连接异常、实际却能搜到」的情况。现在统一后，健康状态与应用内表现一致。

## 保持不变

- 包名 `com.wangshaojie.libretv`、签名和资产文件名规则不变，可直接覆盖升级，源配置、收藏和观看记录都保留。
- 2.0.12 的单一通用安装包、2.0.11 的详情页直接换片源与 IPv6 回退修正、2.0.9 的官方片源清单都保持原样。
- 应用不请求通讯录、定位、摄像头或全盘存储权限；启动时的清单请求只下载一份公开的源地址列表，不上传任何本地数据，也不上报使用统计。

## 验证

- 新增单元测试，覆盖自建连接对 `Content-Length` 与 chunked 分块两种正文的解析，以及跳转、抽样读取和体积上限。
- CI 设备测试仍分两组：Android 5.0 手机（API 21，覆盖证书补丁生效）与 Android TV（API 28，覆盖系统证书库路径），加上单元测试与 Lint 一并在 CI 中运行。
- 已在真实电视（乐视 X3-43S，Android 5.0.1）上覆盖安装本版验证：18 个源全部保留，官方清单拉取后显示「新增 2 个」，测活结果与应用内搜索表现一致，片源搜索正常。

## 已知限制

- 证书地址在 GitHub Raw 上。Windows 版由本地服务拉取、会跟随系统代理，受网络影响较小；Android 版是客户端直连，在部分网络环境下可能拉取不到——此时会静默使用本地已有配置，功能不受影响。
- 个别站点所在域名在部分国内网络会被拦截或重置握手，这属于网络环境问题，与应用无关；这类源在「源管理」里会显示为连接异常。
- 极少数只提供 IPv6 的服务器仍无法直连，这类站点本来在老设备上也连不上。
