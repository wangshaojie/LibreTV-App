# Android 2.0.0 · 海报首页与批量测活

重做安卓的首页、导航、点播详情、直播和源管理，保留 LibreTV 的核心使用方式。

- 首页：精选封面、电影 / 剧集海报、最近观看；分类标签、更多内容与片源搜索。
- 点播：已启用源并发搜索、同名影片合并、海报详情、线路、分批选集与继续观看。
- 直播：分组搜索、频道缓存、频道切换、连接状态与可连接筛选。
- 测活中心：全部源、当前频道列表或全部直播订阅；并发检测、进度、停止、筛选异常和重测；结果保存本机。
- 我的：收藏、历史、推荐来源、含续播进度的 Android 备份、Windows 源配置导入、隐私与完整许可。
- 手机使用底部导航，电视使用侧栏、方向键焦点与横向海报。

选择一份 APK 覆盖安装即可：Legacy 兼容版最低 Android 5.0，推荐 5–7.1 设备；Modern 新版最低 Android 8.0。两版均支持手机和电视，使用原签名及包名，保留原有配置、收藏和历史。内置 7 个点播源、9 个直播源。

频道测活检查网络与媒体片段，实际解码以播放为准。推荐、片源与封面需要联网；EPG、Spider/网页解析、离线下载和云同步尚未提供。未引入会员或广告系统。

附签名 APK、对应源码、中文说明与校验文件。项目为基于 LibreSpark/LibreTV 的非官方原生客户端，采用 AGPL-3.0-or-later。
