# 静观 TV Android 2.0.12 · 合并为一个通用安装包

之前要分发两个安装包：「兼容版」最低 Android 5.0、「新版」最低 Android 8.0。两个包的功能完全一样，区别只在最低系统版本和一份证书补丁的取舍。用户挑版本这件事本身就是多余的负担，本版把它们合成一个包。

## 改动

- **只有一个安装包，最低 Android 5.0（API 21）**，在 Android 5.0 到最新系统的手机和电视上都能安装。
- **应用名统一为「静观 TV」**，不再有「兼容版 / 新版」之分。已安装旧版的应用直接覆盖升级，桌面图标名称会变成「静观 TV」。
- **证书补丁按系统版本自动启用**：
  - Android 8.0 以下：加载内置的 Mozilla 根证书包，补齐旧系统缺失的现代 CA，保证片源站点的 HTTPS 能正常握手；
  - Android 8.0 及以上：直接用系统证书库，不加载补丁。
  - 两种情况下都照常验证证书链和主机名，不绕过任何安全检查。
- **下载页只保留一个 APK**，不用再判断该下哪个。

## 为什么可以合并

两个旧版本共用同一份源代码，差异只有三处：最低系统版本、是否携带证书补丁、桌面图标名称。而证书补丁的加载本来就带系统版本判断——旧版的「兼容版」装在 Android 8.0 以上的机器上时，同样不会加载补丁。也就是说，**旧版「兼容版」在 Android 8.0 以上的运行行为与「新版」完全一致**，本来就没有必要分成两个包。

## 保持不变

- 包名 `com.wangshaojie.libretv`、签名和资产文件名规则不变，可直接覆盖升级，源配置、收藏和观看记录都保留。
- 2.0.11 的详情页直接换片源、2.0.10 的 IPv6 回退、2.0.9 的官方片源清单、2.0.8 的连接中控制面板、2.0.6 的直播自动重连、2.0.7 的全屏沉静式播放都保持原样。
- 应用不请求通讯录、定位、摄像头或全盘存储权限；启动时的清单请求只下载一份公开的源地址列表，不上传任何本地数据，也不上报使用统计。

## 体积

合并后的安装包比原「新版」大约 250 KB（多带一份证书补丁），换成一台设备都能装、且旧系统能正常连片源站点。相对原「兼容版」体积基本不变。

## 验证

- 设备测试改为两组：Android 5.0 手机（API 21，覆盖证书补丁生效）与 Android TV（API 28，覆盖系统证书库路径），加上单元测试与 Lint 一并在 CI 中运行。
- 设备测试新增断言：合并版必须携带证书包且拒绝不受信任的自签名证书；Android 8.0 及以上必须使用系统证书库而不被补丁顶替。
- 已在真实电视（乐视 X3-43S，Android 5.0.1）上覆盖安装本版验证：数据保留、源管理正常、片源搜索正常、官方清单正常拉取。

## 已知限制

- 证书地址在 GitHub Raw 上。Windows 版由本地服务拉取、会跟随系统代理，受网络影响较小；Android 版是客户端直连，在部分网络环境下可能拉取不到——此时会静默使用本地已有配置，功能不受影响。
- 极少数只提供 IPv6 的服务器仍无法直连，这类站点本来在老设备上也连不上。
