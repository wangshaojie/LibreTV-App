# Android 2.0.6 · 直播自动重新接入直播边缘

直播看久了容易自己断：流落后于滑动直播窗口、或网络抖一下，播放器就会报错停住，只能手动按「重试」。本次把直播中断后的恢复交给应用自己完成。

## 改动

- 直播源播放中断时自动重新接入直播边缘并继续观看，画面中央短暂提示「正在重新接入直播…」，不需要手动按「重试」。
- 重连过程中不弹出标题栏和控制面板，观看画面保持干净。
- 触发范围：落后于直播窗口、网络连接失败、网络连接超时、IO 未指定错误、服务器返回异常状态码。
- 保护措施：两次自动重连至少间隔 20 秒；连续失败 3 次后停止自动重连并给出可读提示，避免无限重连反复拉流。重新接入成功即重新开始计数。
- 点播内容保持原样：点播出错仍直接给出可读提示（换线路、选更低清晰度的源），不会被自动重连掩盖。
- 播放错误会写入一条 `LibreTV-Player` 日志，便于在电视上排查具体错误码。

## 保持不变

- 仍然复用同一个播放器实例，重新接入直播只替换媒体源，不销毁重建硬件解码器；2.0.4 修复的早期电视「所有视频有声音没有画面」不受影响。
- 播放页仍是 2.0.5 的全屏沉浸式形态：画面铺满屏幕，控制面板按需呼出并自动淡出。
- 手机端仍不使用沉浸式标志，电视端沿用原有沉浸式做法，媒体键行为不变。

## 适用范围

兼容版最低 Android 5.0（推荐 5–7.1），新版最低 Android 8.0；均支持手机和电视。使用原签名与包名，覆盖安装保留配置、收藏和历史。

已在 Android 5.0.1 真机电视（乐视 X3-43S）上验证：直播中断后应用自动重新接入并继续出画，控制面板、遥控器切台与媒体键均正常。
