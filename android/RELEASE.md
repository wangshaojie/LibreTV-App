# Android 2.0.4 · 修复早期电视「所有视频只有声音没有画面」

在 Android 5.0.1 真机电视（乐视 X3-43S，MStar 芯片）上完整复现并定位该问题。

## 根因

应用此前每切一次台、换一条线路，都会释放并重建 ExoPlayer，也就是销毁并重建电视的硬件 MediaCodec。这台电视的 Android 5.0.1 使用 MStar OMX 插件，解码器释放时 AOSP 的 ACodec 会查询 `OMX_IndexParamAudioMp3`，插件返回 `OMX_ErrorBadParameter`，触发 `ACodec.cpp:3680` 的 `CHECK_EQ` 直接 SIGABRT——应用在播放过程中原生崩溃。

进程死在播放中，电视的视频通路（VideoSetService 的 XC/DS 窗口）被留在坏状态，之后所有视频都只有声音没有画面，电视自带播放器同样全黑，只有重启电视才能恢复。这与「昨晚正常、今天所有视频只有声音」的现象完全吻合。

## 改动

- 播放页复用同一个播放器实例，切台、换线路、选集只替换媒体源，不再销毁重建硬件解码器。
- 解码失败时不再从回调里释放解码器（该路径同样会触发 native 崩溃），改为给出可读提示：说明是本机解码能力问题，并指引更换线路、选择更低清晰度的源，或在电视上所有视频都无画面时重启电视。
- 海报网格改为按键按下即激活，修复部分 Android 版本上回车键无法打开影片详情的问题。
- 使用说明与 README 补充「只有声音没有画面」的排查步骤。

## 适用范围

兼容版最低 Android 5.0（推荐 5–7.1），新版最低 Android 8.0；均支持手机和电视。使用原签名与包名，覆盖安装保留配置、收藏和历史。

附签名 APK、对应源码、中文说明与校验文件。基于 LibreSpark/LibreTV 的非官方原生客户端，采用 AGPL-3.0-or-later。
