# Android 2.0.3 · 改善解码失败提示，修复回车键打开详情

在 Android 5.0.1 真机电视上排查「所有视频有声音但没有画面」后完成本次改动。

## 诊断结论

- 该电视（MStar 芯片，Android 5.0.1）只有硬件解码器（OMX.MS.AVC.Decoder），没有任何软件解码器兜底；芯片拒绝的码流必然表现为「有声音、没画面」。
- 排查中确认解码器可能停在异常状态：电视自带播放器播放同一台上的标准 Baseline 文件完全正常，说明芯片与显示通路本身没有坏。
- 应用侧曾尝试复用播放器实例以减少解码器重建，实机连续切台时触发厂商 OMX 插件的 native abort（ACodec.cpp 中 OMX_IndexParamAudioMp3 的 CHECK_EQ），该方案已撤回，播放器只在界面线程释放。

## 改动

- 解码失败时给出可读提示：说明是本机解码能力问题，并指引更换线路、选择更低清晰度的源，或在电视上所有视频都无画面时重启电视。
- 海报网格改为按键按下即激活，修复部分 Android 版本上回车键无法打开影片详情的问题。
- 使用说明与 README 补充「只有声音没有画面」的排查步骤。

## 适用范围

兼容版最低 Android 5.0（推荐 5–7.1），新版最低 Android 8.0；均支持手机和电视。使用原签名与包名，覆盖安装保留配置、收藏和历史。

附签名 APK、对应源码、中文说明与校验文件。基于 LibreSpark/LibreTV 的非官方原生客户端，采用 AGPL-3.0-or-later。
