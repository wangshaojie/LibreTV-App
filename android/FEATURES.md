# Android 2.0 功能说明

Android 端名为静观 TV，是独立原生客户端，延续 LibreTV 的推荐、全源搜索、直播、源管理和本地数据操作。自 2.0.12 起只分发一个通用安装包，最低 Android 5.0，适配手机及 Android TV；Android 8.0 以下自动补齐根证书库，8.0 及以上使用系统证书库。自 2.0.13 起网络层统一：老电视缺少 IPv6 路由时改走自建的 IPv4 通道并保持正确的 SNI 与证书校验，Android 8.0 以下默认补上 TLS 1.1 / 1.2，测活与海报加载同走这一条通道。自 2.0.14 起官方片源清单改为多地址镜像（主地址不通就换下一个），自建通道与正常请求一样尊重系统 HTTP 代理，源管理里的失败原因会同时写出 IPv6 与 IPv4 两段结果。自 2.0.15 起界面改为浅色单主题（暖白底 + 单一青绿强调色），一级页面不再显示顶栏，弹框全部自绘；手机端触控点一次即响应，详情页切源不会被旧请求覆盖，播放页支持一键全屏，并修复 Android 15 上启动即闪退的问题。自 2.0.21 起修复电视端播放页切集后遥控器失灵的毛病：控制区隐藏前先把焦点挪到根容器（面板被摘掉时不会把焦点一起带走），焦点为空时任何方向键都会先抢回进度条，进度条拿不到焦点就退到播放键，切集连上后重新排空闲隐藏计时，焦点搬走后计时重算。自 2.0.19 起界面改为扁平风：去掉阴影、装饰描边、大圆角和渐变，层次只靠纯色块深浅区分，焦点态改用强调色实心块，播放页那套「暗夜毛玻璃」整体废弃（控制面板改为不透明深色直角块，去掉环境光渐变与胶片颗粒）。自 2.0.23 起：电视端进度条上长按左右键改为渐进加速（0~1.5 秒 25 秒/秒，1.5~4 秒 40 秒/秒，4 秒以上 80 秒/秒），点按仍为 10 秒；长按期间控制区常驻、松手无条件停止、快到片尾自动停（此前按住超过 8 秒会因控制区被空闲隐藏而停不下来，一路快进到片尾）；手机端播放页新增播放 / 暂停键（图标随播放状态切换），手机端图标键统一 42dp。自 2.0.22 起修复电视端「从观看记录打开只有一集」的毛病：观看记录里的条目会带上剧集编号与线路，打开时重新拉一次整部剧的剧集列表并停在原来那一集；老记录没有编号就按片名搜一次兜底，取不到全集才退回单集并提示。自 2.0.18 起观看记录与搜索记录均可删除：可单条删除或一键清空，删除连带清掉续播进度。

| 功能 | Android 2.0 行为 |
| --- | --- |
| 界面 | 浅色单主题；扁平风（无阴影 / 装饰描边 / 大圆角 / 渐变），层次靠纯色块深浅区分，焦点用强调色实心块；一级页面无顶栏，二级页面留返回键与页面名；弹框自绘 |
| 首页推荐 | 电影与剧集海报横排、精选封面、最近观看；推荐按片名查找可用片源 |
| 分类浏览 | 电影 / 剧集、分类标签、海报网格和更多内容 |
| 推荐降级 | 豆瓣加载失败后尝试 CMS 最近更新；本机缓存可继续显示 |
| 全源搜索 | 并发查询已启用的 CMS 源，逐源展示结果，同名影片合并后选择片源 |
| 详情与选集 | 海报、年份、简介、线路、剧集；长剧集列表分批展示；详情页内直接切片源 |
| 原生播放 | 全屏沉浸式播放页；HLS / DASH / MP4、续播、自动下一集、倍速、画面比例与重试 |
| 播放全屏 | 手机端一键切横屏并收起全部控件，再点画面切回竖屏；电视端不显示该按钮 |
| 直播 | M3U 订阅、分组与搜索、最近列表缓存、上一台 / 下一台与频道键；中断后自动重新接入直播边缘 |
| 源批量测活 | 全部点播与直播源的访问、内容解析、数量与延迟 |
| 频道批量测活 | 当前筛选列表，或所有已启用直播订阅；按地址去重 |
| 测活控制 | 有界并发、进度、停止、可连接 / 异常筛选及异常重测 |
| 测活结果 | 本机保存；源管理和直播列表展示状态，直播可只看可连接频道 |
| 源管理 | 添加、编辑、启用 / 停用、删除、单独检测与配置迁移 |
| 我的 | 收藏、历史、推荐来源、配置备份、隐私说明和完整开源许可 |
| 记录清理 | 观看记录可单条删除（长按卡片 / 遥控器菜单键）或一键清空，搜索记录同样可删；删除连带清掉续播进度，确认框焦点默认落在「继续浏览」 |
| 观看记录打开 | 点播从观看记录打开时重新拉取全集并定位到原来那一集（老记录按片名兜底搜索），不再出现「只有一集 / 没有更多剧集」 |
| 数据迁移 | 支持 Android 配置、LibreTV SourceList 和 Windows 配置中的源信息；Android 备份包含续播进度 |
| 自适应导航 | 手机底部导航，电视侧栏；焦点边框、方向键、确定 / 返回 / 菜单键 |
| 异常诊断 | 崩溃现场记入应用私有目录，下次启动以「异常记录」展示堆栈，不自动上传 |

测活验证的是网络连通性：HLS 会继续检查子播放列表和媒体片段，返回网页的地址不会判为有效流。设备能否解码、加密或地区限制仍以实际播放结果为准。

EPG、Spider/网页解析、离线下载和云账号同步尚未提供。本版本没有引入付费、广告或会员系统。
